# G Dhilli Prasad — Portfolio

A responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser. For best results, use a local static server.

## Deploy with AWS Amplify Hosting
1. Push these files to a GitHub repository.
2. In AWS Amplify, choose **Host web app** and connect the repository.
3. Select the branch and keep the build settings empty/default for a plain static site (no build command or output directory is required when the app is served from the repository root).
4. Deploy and test the generated URL on desktop and mobile.
